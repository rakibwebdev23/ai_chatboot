# APS Chatbot

A professional, embeddable chatbot widget built with Next.js and Tailwind CSS.

## 🌟 Features
- **Easy Integration**: Single script tag installation.
- **Responsive Design**: Works perfectly on mobile and desktop.
- **Fast & Lightweight**: Minimal impact on page load times.
- **Customizable**: Smooth animations and premium aesthetics.

## 🚀 How to Use on External Websites

To use this chatbot on any CMS or static website, add this script tag:

```html
<script src="https://office-ai-chatboot.vercel.app/widget.js"></script>
```

For detailed step-by-step instructions for **WordPress, Shopify, Wix, and Squarespace**, please refer to the [CMS Installation Guide](./CMS_INSTALLATION_GUIDE.md).

## 🛠 Development Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build & Export**:
   ```bash
   npm run build
   ```
   The static files will be generated in the `out/` directory.
